# ДЗ № 2. Прогноз продаж Online Retail

Прогнозирую продажи товара 20728 (LUNCH BAG CARS BLUE) в штуках. Использую подготовленные ряды из ДЗ № 1. После исключения крайних дней и неполных периодов осталось 372 дня, 52 недели и 11 месяцев. Данные Daqing Chen, лицензия CC BY 4.0. [UCI Online Retail](https://archive.ics.uci.edu/dataset/352/online-retail).

Сравниваю наивный прогноз, экспоненциальное сглаживание, AutoReg, ARIMA(1, 1, 0) и градиентный бустинг. На каждом старте модель обучается на всех продажах до даты прогноза. В тесте получилось 30 дневных, 9 недельных и 3 месячных старта.

## Результаты

Лучший результат по WAPE на всех горизонтах показала **AutoReg**.

| Частота | Горизонт, шагов | WAPE, % |
| --- | ---: | ---: |
| День | 1 | 53,0 |
| День | 7 | 55,3 |
| День | 31 | 66,2 |
| День | 61 | 72,0 |
| Неделя | 1 | 22,6 |
| Неделя | 4 | 19,2 |
| Неделя | 8 | 24,6 |
| Месяц | 1 | 20,7 |
| Месяц | 2 | 31,3 |

Дневная ошибка растёт с горизонтом. В недельном ряду у AutoReg ошибка на 4 шагах ниже, чем на одном. На два месяца вперёд ошиблись сильнее все модели. На графиках видно, что дневные модели сглаживают часть пиков продаж. Месячную оценку стоит воспринимать осторожно из-за трёх стартов.

## Запуск

Установите зависимости командой `python -m pip install -r requirements.txt`. Откройте [forecast.ipynb](forecast.ipynb) в Jupyter или VS Code, выберите это окружение и запустите все ячейки. Проверено на Python 3.13.

- [Метрики](results/metrics.csv) содержат MAE, RMSE и WAPE по всем шагам горизонта, а также MAE отдельно на последнем шаге.
- [Прогнозы](results/predictions.csv) содержат факт и прогноз для каждой модели и точки старта. Для горизонта h берутся строки с номером шага от 1 до h.
