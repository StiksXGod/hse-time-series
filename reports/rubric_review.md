## Фактические проверки

- Зависимости установлены в новое изолированное окружение Python 3.13.3 из имеющегося
  локального кеша wheel-пакетов. `pip check` не обнаружил конфликтов.
- Все ячейки выполнены с начала в новом `ipykernel.inprocess`, созданном в новом процессе Python.
  Ядро действительно исполняет код; выходные данные получены из его сообщений IOPub.
  Состояние интерактивных сессий и кеш транзакций не использовались.
- Исполнитель проверяет последовательные execution counts, отсутствие ошибок, наличие
  не менее десяти PNG, соответствие числа изображений в HTML и Notebook, валидность nbformat.
- 24 автоматических теста прошли. Протокол: `reports/test_results.xml`.
  Отдельный тест проверяет сохранение stdout, настоящего рисунка и результата выражения
  при последовательном исполнении двух ячеек нового ядра.
- Проверены суммы продаж, кредиты, календарь, число потерянных наблюдений после разности,
  отсутствие запрещённого товара и неизменность SHA256 исходного Excel.
- Все 12 PNG просмотрены: кириллица читается, обрезанных заголовков и пересечений подписей нет.
- Выводы Notebook и README используют общую функцию; числовые результаты сверены с CSV/JSON.
  Фактическое время финального запуска и количество выводов — в `reports/verification.json`.

## Ограничения и оценка

По содержанию работа соответствует всем критериям и **претендует на 40/40**:
оформление 10/10, полнота 20/20, корректность 10/10. Это самостоятельная оценка
соответствия рубрике, а не гарантия оценки преподавателя.

Неразрешимая по одному датасету неопределённость — полнота регистрации в пустые дни,
реальный календарь работы и отсутствие данных о запасах/акциях. Эти ограничения
явно учтены в постановке метрики, анализе чувствительности и выводах. Дедупликация
полных повторов — допущение, поскольку идентификатора строки счёта нет; её влияние мало
и показано. История слишком короткая для достоверного годового цикла.

Сетевое скачивание исходника с UCI в этой среде не проверено: оригинальный Excel уже
предоставлен, а исходящие соединения ограничены. Код загрузки, извлечения архива и проверки
SHA256 проверен на локальной контролируемой фикстуре; сама фикстура не использовалась
в исследовании. Обычный TCP/IPC-транспорт Jupyter запрещён средой, поэтому проверен
реальный kernel без сокетов. Команда стандартного nbclient предоставлена, но её успешный
запуск здесь не заявляется. Это технические ограничения проверки, а не пропуски анализа.

Git-репозиторий, коммиты и публикация не создавались по прямому указанию пользователя.
Для окончательной сдачи по исходному документу потребуется разместить готовые файлы
на GitHub позднее. Этот шаг сознательно исключён из текущей задачи уточнением пользователя.
